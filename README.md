ExifRemovalTool
===============

[![Python 3.10.11](https://img.shields.io/badge/python-3.10.11-blue.svg)](https://www.python.org/downloads/release/python-31011/)
[![Pillow 12.2.0](https://img.shields.io/badge/Pillow-12.2.0-blue.svg)](https://pypi.org/project/Pillow/)

ExifRemovalTool is a Python script for viewing and removing EXIF data from images.

Install dependencies:

```shell
pip install -r requirements.txt
```

View EXIF data:

```shell
python main.py -v image.jpg
```

Remove EXIF data:

```shell
python main.py -r image.jpg
```
